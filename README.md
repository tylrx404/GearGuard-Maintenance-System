🛠️ GearGuard – Maintenance Management System
GearGuard is a full-stack maintenance management application designed to help organizations track equipment, manage maintenance teams, and handle maintenance requests through a clear, role-based workflow.
🔍 Problem
Managing equipment breakdowns and scheduled maintenance becomes complex without a centralized system that clearly connects assets, teams, and repair requests.
💡 Solution
GearGuard provides:
Centralized equipment tracking
Role-based access for Employees and Maintenance teams
Kanban workflow for maintenance requests
Calendar view for preventive maintenance
Fully dynamic data (no dummy UI)
👥 Roles
Employee: Create and track maintenance requests
Maintenance Team: Schedule, update, complete, or scrap requests
⚙️ Key Features
Equipment & team management
Corrective & preventive maintenance
Drag-and-drop Kanban (unlimited requests)
Preventive maintenance calendar
Scrap logic for unusable equipment
Real-time dashboards & charts
🧱 Tech Stack
Frontend: Next.js, React, Tailwind CSS
Backend: Node.js, Next.js API Routes
Database: MongoDB
🚀 Run Locally
pnpm install
pnpm dev
🏁 Summary
GearGuard demonstrates a production-style, workflow-driven maintenance system focused on clarity, usability, and real-world enterprise needs.
